# دليل التشغيل والتطوير المحلي (Local Development Runbook)
## منظومة الحرم الجامعي والمواقف الذكية — جامعة فهد بن سلطان (FBSU)

يوضح هذا الدليل كيفية تشغيل بيئة العمل المتكاملة للمنظومة على جهاز المطور بأقل خطوات ممكنة باستخدام **Docker Compose**.

---

### المتطلبات الأساسية (Prerequisites)
1. **Docker Desktop** مثبت وشغال.
2. توفر منفذ **80** (للواجهة الأمامية) ومنفذ **8080** (للباك إند) ومنفذ **5432** (لقاعدة البيانات PostgreSQL).

---

### خطوات التشغيل بخطوة واحدة (One-Step Run)

1. **تجهيز متغيرات البيئة:**
   قم بنسخ ملف المتغيرات النموذجي `.env.example` إلى `.env`:
   ```bash
   cp .env.example .env
   # أو في PowerShell:
   Copy-Item .env.example .env
   ```

2. **بناء وتشغيل جميع الحاويات:**
   ```bash
   docker compose up --build -d
   ```

3. **متابعة إقلاع الخدمات والتأكد من حالتها الصحية (Health Checks):**
   ```bash
   docker compose ps
   ```
   ستلاحظ أن:
   - خدمة قاعدة البيانات `postgres` تبدأ أولاً وتخضع لـ `pg_isready`.
   - خدمة الباك إند `backend` لا تقلع إلا بعد تمام صحة قاعدة البيانات، وتخضع لـ `/actuator/health`.
   - خدمة الواجهة `frontend` تقلع وتخدم الـ SPA وتعيد توجيه طلبات `/api/` إلى الباك إند تلقائياً.

---

### الروابط المتاحة بعد التشغيل

| الخدمة | الرابط المحلي | الوصف |
| :--- | :--- | :--- |
| **واجهة المنظومة (React SPA)** | `http://localhost/` | التطبيق التفاعلي للمنظومة |
| **توثيق الواجهات (Swagger UI)** | `http://localhost:8080/swagger-ui.html` | توثيق الـ REST APIs |
| **فحص صحة الخادم (Actuator Health)**| `http://localhost:8080/actuator/health` | تقرير جاهزية الخادم وقاعدة البيانات |
| **قاعدة البيانات (PostgreSQL)** | `localhost:5432` | قاعدة البيانات الرئيسية (`fbsu_campus_db`) |

---

### إيقاف البيئة أو إعادة ضبطها

* **إيقاف الحاويات مع الاحتفاظ بالبيانات:**
  ```bash
  docker compose down
  ```

* **إيقاف الحاويات وحذف قواعد البيانات بالكامل (Clean Reset):**
  ```bash
  docker compose down -v
  ```
